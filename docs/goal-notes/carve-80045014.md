`fn_8004509C` is above the claim. Listing the carve in `files.cmake` therefore adds one reference
to the port's link that dtk's `auto_03_8004509C_text.o` satisfies for the DOL but the port does
not carry. So it gets the announced empty-body stand-in `stub_193`.
