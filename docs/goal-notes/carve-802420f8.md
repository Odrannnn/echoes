## What the two functions are

Neither is named by retail (`config/G2ME01/symbols.txt:10232-10233`, both `fn_<addr>`
placeholders), so both are byte-shape twins of already-matched code, copied under the `fn_` name:

- **`fn_802420F8`, 0x3C = 60 bytes, 15 instructions** - `__dt__5CMainFv` (0x800087DC,
  `src/MetroidPrime/main.cpp:517`, `CMain::~CMain() {}`) word for word: `mr. r31,r3 / beq` guards
  the receiver, `extsh. r0,r4 / ble` re-tests the flag as a **short** (a `bool` would give
  `extsb.`), `if (flag > 0)` is **inside** `if (self)`, and the epilogue's `mr r3,r31` says the
  return is `void*`. The twin's `bl Free__7CMemoryFPCv` is the only call, so
  `Free__7CMemoryFPCv` is declared `extern` and never defined.
- **`fn_80242134`, 0xC = 12 bytes, 3 instructions** - `DisableFog__Q29CGameArea8CAreaFogFv`
  (0x80056DE8, `src/MetroidPrime/CGameArea.cpp:1592`, `mFogMode = kRFM_None;`): `li r0,0` /
  `stw r0,0(r3)` / `blr`, written `void fn_80242134(int* self) { *self = 0; }`.

Both are the same two shapes as the carve immediately below (`Carve8023C950.c`, 0x8023C950..0xC98),
so this pair is the second copy of one deleting-destructor step and one zero-word store that the
seed tool found twice in the same unclaimed range.

## Who calls them (measured, and it constrains nothing)

Both call sites are in dtk's unclaimed `auto_03_800B743C_text` (the `auto_03_800B7928_text`
listing is the duplicate of the same code), so nothing of ours needs these symbols and the port's
undefined count does not move:

- 0x800B7F14 / 0x800B7F1C: `mr r3,r17 ; li r4,-1 ; bl fn_802420F8` in `fn_800B7928`'s destructor
  walk over its stack temporaries (`r17` = `r1+0xc4`, set at 0x800B7954). `-1` is MWCC's "destroy,
  do not free me afterwards", so the free-through-to-self is dead at those sites and is **not**
  dead in the source - which is why the guard stays in the body.
- 0x800B7F5C: `addi r3,r31,0x44 ; bl fn_80242134` in `fn_800B7F44`, whose next three words
  (`+0x4c`, `+0x54`, `+0x5c`) go to `fn_8024203C` instead.

prompt says "the trailing `.cpp` is required", which is the spelling of a `.cpp` unit; for a `.c`
carve, `./tools/flip_test.sh MetroidPrime/ScriptLoader/Carve802420F8.cpp` prints
`SKIP ... not listed in configure.py` and `kept: 0 / 1 ... skipped: 1` - it is a skip, not a
failure, and easy to misread as one. The `.c` name passes.

about the other 17. `flip_test.sh` and the DOL sha1 are the measurements.
