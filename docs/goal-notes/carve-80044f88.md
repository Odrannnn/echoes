## A lesson this cost a few minutes: MWCC's C mode is C89

The twins' sources are C++ and write `for (int remaining = n; ...)`. In `-lang=c` mwcceppc rejects a
declaration in the for-init (`expression syntax error` at the `int`), so the C spelling has to hoist
it out. It costs no instruction: the twin declares `int n` as a parameter and the hoisted
`int remaining = n;` is the same `mr`.
