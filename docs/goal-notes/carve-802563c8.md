## The twin, and the one thing about it that does not transfer

The seed's twin is `fn_80004438` (0x80004438, 0x20, 8 instructions,
`src/MetroidPrime/Carve80004438.c`, `Matching`). Read as a diff of two objdump listings, the two
are the same eight words apart from the `bl` displacement (`48 00 01 9d` vs `48 00 00 15`).

**Its *body* does not copy, and the difference is in the arguments.** The twin is
`void fn_80004438(void* self) { fn_80004458(self); }` — one argument — because its callee
`fn_80004458` materialises `li r4,-1` itself (MWCC's "destroy, do not free me" flag;
`include/rstl/construct.hpp:84-95`, and the same four-function chain at 0x80255A0C). Here
`fn_802563C8` materialises nothing and its callee uses **both** incoming registers. Measured off
`main.elf` at 0x80256570 (`asm/auto_03_80255D2C_text.s:630-655`): `mr r30,r3 / mr r31,r4`, then
`lwz r5,0x8(r31)`, `mr r4,r31`, `addi r3,r30,0x14`, `sth r0,0x10(r30)`,
`bl __ct__6CAABoxFR12CInputStream`, and `mr r3,r30` before `blr`. So the second argument is a
pointer it dereferences and hands to a `CAABox(CInputStream&)`, and the result is the receiver.

The one caller in the DOL confirms both halves. `grep -rn 'bl fn_802563C8' build/G2ME01/asm/`
returns exactly one hit — 0x802561B8, inside `fn_80256158` (0x80256158, 0xA0 bytes, unclaimed and
left in dtk's range) — and the three instructions before it are
`addi r3,r1,0xc / mr r4,r28 / mr r5,r31`. Two live arguments, no `li r4` anywhere in the call
sequence to supply a second one. So the file spells it as a two-argument forwarder returning its
callee's result:

```c
void* fn_802563C8(void* self, void* other) { return fn_80256570(self, other); }
```

A one-argument spelling compiles to the same eight words with r4 dead, so `flip_test` alone would
not have caught the wrong reading here; the argument count is read off the callee and the caller,
not off the twin.

Retail names the receiver's class nothing that this claim reaches, so the two parameters stay
pointers. The file does not claim what `fn_80256570` constructs.
