## The one spelling that mattered, and one trap worth not repeating

* **The body was byte-exact on the first compile** (the item's `reason` had already measured it in
  the seeding run: `carve_diff.sh 80004744 54`: 21/84 both sides, 2 differing).  The spelling that
  produced it: `extern void Free__7CMemoryFPCv(const void*);` plus a `struct` whose `void*` member
  sits at +0xC, declared `void* fn_80004744(struct ..., short flag)` and returning `self`.  The
  `short` is load-bearing (`extsh. r0,r31` / `ble`); the receiver guard `if (self)` gives retail's
  `mr. r30,r3` / `beq`, and retail's own `mr r31,r4` before it falls out of the parameter move.
* **Trap (measured this run): `tools/carve_diff.sh` against the wrong object passes for the wrong
  reason.**  `build/G2ME01/obj/<unit>.o` is **dtk's split of retail's bytes** and
  `build/G2ME01/src/<unit>.o` is **ours** (`build.ninja`: `build build/G2ME01/src/...: mwcc_sjis`).
  Diffing `obj/` reports "21/84 both sides, 2 differing" - the two values differ only because
  dtk leaves the `bl` placeholders unresolved, so it is retail against itself: a check that cannot
  fail.  Use the `src/` object (or `unit_fit.sh`, which resolves the right one), and confirm the
  `main.elf` link input list names the `src/` object, as above.
